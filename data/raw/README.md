# data/raw

Put the five files downloaded from the challenge page here
(https://challengedata.ens.fr/challenges/162, Files section, after registering):

- clinical_train.csv
- clinical_test.csv
- molecular_train.csv
- molecular_test.csv
- target_train.csv

These files are NOT on GitHub: the Challenge Data terms of use do not allow
the data to be redistributed. `.gitignore` keeps them out of the repository.
