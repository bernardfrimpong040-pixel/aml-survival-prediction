# Packages for the AML survival project.
#
# Install in TWO steps (Windows, Python 3.13):
#   pip install -r requirements.txt
#   pip install --no-deps scikit-survival
#
# Why two steps? scikit-survival lists "ecos" as a dependency, but ecos has no
# ready-made Windows package for Python 3.13 and needs a C++ compiler to build.
# ecos is only used by one survival-SVM function this project never uses, so we
# install scikit-survival without it. "pip check" will mention ecos - that is expected.
#
# xgboost-cpu (added in Stage 5) is the CPU-only build of XGBoost: same
# library, much smaller download than "xgboost" (which bundles GPU code).
